# Messaging Features

{% hint style="info" %}
📘 **In this guide, you'll learn how to:**

* Send emojis, images, and files
* Use message templates for faster replies
* Use Dr.OZ AI to assist with customer conversations
{% endhint %}

### 1. Message Tools

The message field in the **Inbox** includes tools for adding emojis, images, files, and saved message templates. You can also open Dr.OZ AI directly from the chat window.

<figure><img src="../.gitbook/assets/image (786).png" alt=""><figcaption></figcaption></figure>

#### ① Emoji

Select the **Emoji** icon to add an emoji to your message.

> 💡 Emojis can help make conversations feel more friendly and natural.\
> For formal notices or important information, we recommend using them sparingly.

***

#### ② Image

Select the **Image** button to send an image to the customer.

**Common use cases include:**

* Clinic location information
* Event or promotion details
* App installation instructions
* Instructions on how to use a service

***

#### ③ Attach a File

Select the **File (clip)** button to attach and send a file to the customer.

> 💡 File delivery may be restricted depending on the file type or size. If a file fails to send, check the file format and size before trying again.

***

#### ④ Message Templates

Select the **Template** button at the bottom of the chat window to view your saved message templates.

Choose a template to insert its content into the message field. You can edit the message before sending it if needed.

1. Select the **Template** button at the bottom of the chat window.
2. Choose the template you want to use.
3. The template content will appear in the message field.
4. Edit the message as needed, then send it to the customer.

**Common use cases include:**

* Clinic opening hours
* Clinic location information
* Appointment information requests
* App installation instructions
* Appointment confirmation messages

> 💡 Save frequently used replies as templates to reduce response time and provide more consistent customer service.

***

#### Using Templates with Variables

If a patient is linked to the conversation, templates that contain variables can automatically insert information associated with that patient.

For example, a template may automatically populate details such as the patient's:

* Name
* Phone number
* Other linked patient information supported by the template

**\[Insert image: Template with patient information automatically populated]**

> ⚠️ Before sending a variable-based template, always check that the patient information has been inserted correctly.\
> If no patient is linked to the conversation, the variable name may remain visible in the message instead of being replaced with patient information.

***

#### ✅ If No Templates Are Available

If no templates have been created, selecting the **Template** button will display **“No templates available.”**

To use this feature, create a message template first.

> 📌 For instructions on creating and managing templates, see the [**Message Template Management**](message-template-management.md) guide.

***

### 2. Dr.OZ AI Features

The **Dr.OZ AI** tab on the right side of the screen helps staff review conversations, generate suggested replies, and handle appointment-related tasks while chatting with customers.

> 💡 Dr.OZ AI can help reduce repetitive work and make customer conversations faster and more efficient.

#### Key Features

* Summarize conversation history
* Identify the customer's inquiry intent
* Generate AI-suggested replies
* Create, update, or cancel appointments during a conversation
* Translate messages into different languages.
