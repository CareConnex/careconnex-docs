# AI 다국어 상담

{% hint style="info" %}
📘 **이 페이지에서 배우는 내용**

* 외국어 문의에 AI 추천 답변을 활용하는 방법
* 고객 언어에 맞춰 답변이 생성되는 방식
* 여러 상담 채널에서 다국어 상담을 사용하는 방법
* 다국어 상담 사용 시 참고사항
{% endhint %}

### **AI 다국어 상담** 기능

**문의 > 수신함 Dr.OZ AI** 다국어 상담 기능은 외국어 문의가 들어오면 고객의 언어를 자동으로 인식하고 대화 내용을 분석하여 관리자가 외국어 문의를 빠르게 파악하고 대응할 수 있도록 도와줍니다.&#x20;

① 오른쪽의 **Dr.OZ AI** 탭을 선택합니다.

② **제안 응답**에서 고객의 언어로 생성된 답변과 한국어 번역을 확인합니다.

③ 상담 내용에 적합한 제안 응답의 **적용 아이콘(비행기 모양)**&#xC744; 클릭합니다.

* 선택한 답변이 메시지 입력창에 자동으로 입력됩니다.
* 입력된 내용을 확인하거나 필요한 경우 수정한 후 **Enter 키 또는 전송 버튼**을 눌러 고객에게 전송합니다.

### 💡 참고 사항

* 고객에게 제안하는 답변은 고객이 사용한 언어를 기준으로 자동 생성됩니다.
* Dr.OZ AI가 고객의 언어를 자동으로 인식하기 때문에 상담원이 매번 번역 언어를 직접 선택할 필요는 없습니다.
* AI 번역 및 추천 결과는 상담을 지원하기 위한 기능입니다. 고객에게 전송하기 전에 답변 내용이 상담 의도와 일치하는지 확인해 주세요.
* **Dr.OZ 설정 > 메뉴 언어**를 한국어로 설정하더라도, 고객의 언어가 감지되면 제안 응답도 고객의 사용한 언어에 맞춰 생성됩니다.&#x20;
