# Basic Settings

{% hint style="info" %}
📘 **In this guide, you'll learn how to:**

* Set up your clinic profile and basic information
* Configure clinic operating hours and the default tax rate
* Change the admin dashboard theme
* Set the default language for the Dr.OZ Admin
* Configure appointment reminder timing
{% endhint %}

## Clinic Settings

### Clinic Settings Information

To access **Settings > Clinic Settings**, you will need to verify your administrator password for security.

1. Enter the password for the account you are currently logged in with.
2. Click **\[Confirm]**.
3. Once verified, you will be taken to the **Clinic Settings** menu.

> 💡 Clinic Settings contains information that can affect clinic operations, so password verification is required when accessing this section.

***

### Clinic Profile

Set the logo image used for your clinic in Dr.OZ.

To upload your own clinic logo:

1. Select **Image Upload**, then click the upload area or drag and drop an image file.
2. Adjust the **size and position** of the logo.
3. Click **\[Save]** to apply the changes.

<figure><img src="../.gitbook/assets/image (862).png" alt=""><figcaption></figcaption></figure>

> 💡 You can upload **JPG or PNG** files up to **10 MB**.

***

### Clinic Information

View and update the basic information registered for your clinic in Dr.OZ.

Select the **pencil icon** next to an editable field to make changes.

The clinic information includes:

* Clinic ID
* Clinic Name
* Tax ID
* Representative Name
* Address
* Country
* Timezone

<figure><img src="../.gitbook/assets/image (863).png" alt=""><figcaption></figcaption></figure>

> 💡 **Country** and **Timezone** are displayed based on the region where the clinic operates.

***

### Operating Hours

Set your clinic's opening and closing times for each day of the week. If the clinic is closed on a particular day, you can remove the corresponding time slot.

1. To add another operating period, select **\[+ Add Time]**.
2. Once your settings are complete, click **\[Save]** to apply them.

<figure><img src="../.gitbook/assets/image (865).png" alt=""><figcaption></figcaption></figure>

***

### Billing Settings

Set the default tax rate that will be applied to newly created billing items.

1. Enter the **Default Tax Rate (%)**.
2. Click **\[Save]**.

<figure><img src="../.gitbook/assets/image (867).png" alt="" width="563"><figcaption></figcaption></figure>

> 💡 The default tax rate will be automatically applied to billing items created after the setting is saved.

***

### Theme

Change the appearance of the Dr.OZ Admin.

The following themes are currently available:

* **Default Light**
* **Aubergine**
* **Ocean Blue**
* **Emerald**
* **Nocturne**

Select your preferred theme to apply it to the admin dashboard.

## General Settings

**Basic Settings is divided into Clinic Settings and General Settings.**

Under the **General** tab, you can set the default language for the Dr.OZ Admin and configure when appointment reminders are sent.

***

### Language

Choose the default language used in the Dr.OZ Admin.

Currently supported languages:

* **English**
* **Korean**

The Dr.OZ Admin will be displayed in the language you select.

### Reminder Settings

Set the default reminder timing for appointments sent to **members (staff)** and **patients**.

📌 **Path: Settings > General > Reminder**

Reminders are sent based on the appointment time of a **confirmed schedule card**.

You can configure reminder timing separately for members and patients, and you can add multiple reminders if needed.

#### ✅ Set Up a Reminder

1\. Under either the Member or Patient section, choose the day and time for the reminder.\
2\. Select **\[+ Add Reminder]** to add the reminder.\
3\. Click **\[Save]** to apply the settings.

<figure><img src="../.gitbook/assets/image (868).png" alt="" width="563"><figcaption></figcaption></figure>

> 💡 Reminder timing can be configured separately for members and patients.

✅ **Reminder Timing Options**

You can choose when the reminder should be sent relative to the confirmed appointment time:

* At the appointment time
* 15 minutes before
* 30 minutes before
* 1 hour before
* 2 hours before
* 4 hours before
* 8 hours before
* 12 hours before

> 💡 For example, if an appointment is scheduled for **3:00 PM** and the reminder is set to **30 minutes before**, the reminder will be sent at **2:30 PM**.

***

#### Set Multiple Reminders

To send more than one reminder for the same appointment, select **\[+ Add Reminder]** again.

For example, you can set reminders for:

* **30 minutes before the appointment**
* **2 hours before the appointment**

Each reminder is sent separately at its configured time. To remove a reminder, select the **delete icon** next to it.

<figure><img src="../.gitbook/assets/image (869).png" alt="" width="310"><figcaption></figcaption></figure>

> 💡 **Basic Settings determines when appointment reminders are sent.**\
> To configure the **message content and detailed sending conditions** for treatment, consultation, and event reminders, see the **Reminder Management** guide.
