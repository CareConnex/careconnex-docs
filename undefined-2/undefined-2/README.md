# 환자 상세 정보

### 환자 상세 정보 화면

환자 상세 정보 화면은 **정보, 내원 이력, 티켓, Credit Wallet, Plato 의료기록**의 5개 탭으로 구성되어 있습니다.

**📌 경로: 환자 > 환자 선택 > 탭별 선택**

<figure><img src="../../.gitbook/assets/image (188).png" alt=""><figcaption></figcaption></figure>

### 탭별 주요 기능

각 탭에서 확인하고 관리할 수 있는 주요 기능을 안내합니다.

{% tabs %}
{% tab title="정보" %}
#### Tab 1. 정보

환자의 기본 정보를 확인하고 수정합니다.

**주요 기능**

* 이름, 연락처, 생년월일 등 기본 정보를 확인합니다.
* 환자 정보를 수정하거나 삭제할 수 있습니다.

> 💡 자세한 내용은 **'**[**정보 탭**](undefined.md)**'** 가이드를 참고하세요.
{% endtab %}

{% tab title="내원 이력" %}
#### Tab 2. 내원 이력

예약 및 방문 기록을 조회하고 예약을 관리합니다.

**주요 기능**

* 예약 내역을 조회합니다.
* 예약을 수정하거나 삭제할 수 있습니다.
* 예약별 티켓 및 청구 내역을 확인합니다.

> 💡 자세한 내용은 [**'내원 이력 탭'**](undefined-1.md) 가이드를 참고하세요.
{% endtab %}

{% tab title="티켓" %}
#### Tab 3. 티켓

티켓을 추가하고 티켓의 상세 내용을 확인 및 관리할 수 있습니다.

**주요 기능**

* '사용 가능 티켓'을 확인합니다.
* 예약과 연결된 티켓 사용 및 잔여 횟수를 조회합니다.
* 새로운 티켓을 추가할 수 있습니다.

> 💡 자세한 내용은 [**'티켓 관리'**](../../undefined-5/undefined.md) 가이드를 참고하세요.


{% endtab %}

{% tab title="Credit Wallet" %}
#### Tab 4. Credit Wallet

환자의 Credit Wallet을 충전하고, 잔액을 조정하거나 Wallet 상태를 관리할 수 있습니다.

**주요 기능**

* Credit 충전
* Credit 잔액 조정 및 환불
* Wallet 상태 변경

> 💡 자세한 내용은 **'**[**Credit Wallet 탭'**](credit-wallet.md) 가이드를 참고하세요.
{% endtab %}

{% tab title="Plato 의료기록" %}
#### Tab 5. Plato 의료기록

Plato 환자를 연결하고 의료기록과 예약·청구 정보를 조회할 수 있습니다.

**주요 기능**

* Plato 환자 연결
* 진료 기록 조회
* 예약 및 청구 내역 조회

> 💡 자세한 내용은 [**'Plato 의료기록 탭**'](plato.md)  가이드를 참고하세요.
{% endtab %}
{% endtabs %}
