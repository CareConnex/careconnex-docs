# 환자 등록

## 환자 등록 및 검색

### 신규 환자 등록

1. 환자 > **\[환자 추가]**&#xB97C; 클릭합니다.
2. 환자 추가 팝업에서 정보를 입력합니다.
3. 필수 항목 입력 후 **\[추가]**&#xB97C; 클릭하여 등록을 완료합니다.

<figure><img src="../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure>

```
✅ 필수 입력 항목
- 이름
- 생년월일
- 성별
- 휴대전화번호
- 국적
- 멤버십
```

* **선택 입력 항목:** 메모, 유입 경로, 이메일, 포인트&#x20;

> ⚠️ `*` 표시는 필수 입력 항목을 의미하며, 모든 필수 항목을 입력해야 환자를 등록할 수 있습니다.

***

### 환자 검색&#x20;

좌측 상단의 **검색창** 또는 **필터** 기능을 사용하여 환자를 검색할 수 있습니다.&#x20;

검색어를 입력하거나 필터 조건을 설정하면 조건과 일치하는 환자가 즉시 조회됩니다.

#### **검색창**

* 환자이름, 전화번호, 환자메모, 환자번호 등으로 검색할 수 있습니다.&#x20;
* 환자번호는 전체 번호뿐 아니라 영문 또는 뒷자리 번호만 입력해도 검색할 수 있습니다.\
  (예: `DEMO-020` → `020`으로 검색)

<figure><img src="../.gitbook/assets/image (179).png" alt=""><figcaption></figcaption></figure>

#### **필터 검색**

검색 필터를 활용하면 '생년월일, 성별, 멤버십' 등 다양한 조건으로 검색할 수 있습니다.&#x20;

필터 > 검색 필터 > 조건 선택 후 **\[확인]** 버튼을 누르면 원하는 조건으로 검색됩니다.       &#x20;

<figure><img src="../.gitbook/assets/image (180).png" alt=""><figcaption></figcaption></figure>

> 💡 검색 후 필터 옆 **새로고침(🔄) 아이콘**을 클릭하면 적용된 검색 조건이 초기화됩니다.

***

### **❓ 자주 묻는 질문**

**Q. 환자 등록 시 선택한 멤버십을 환자도 볼 수 있나요?**  \
A. 네, 가능합니다. 등록 시 선택한 멤버십 등급은 환자 앱(마이 페이지 > 내병원)에서도 동일하게 표시됩니다.

**Q. 환자 정보를 일괄 등록할 수 있나요?** \
A. 네, 가능합니다. 환자 정보(필수값 포함) 파일을 닥터오즈 담당자에게 별도 전달하면 등록을 지원해 드립니다.&#x20;
