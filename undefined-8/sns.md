# SNS 계정 연동

{% hint style="info" %}
📘 **이 페이지에서 배우는 내용**

* 인스타그램 계정 연결 방법
* **페이스북 메신저** 계정 연결 방법
* 왓츠앱 계정 연결 방법
* 여러 SNS 계정을 연결하는 방법
{% endhint %}

## SNS 계정 메뉴

Dr.OZ에 병원에서 운영 중인 **인스타그램, 페이스북 메신저, WhatsApp 비즈니스 계정**을 연결하여 각 채널로 들어오는 환자 문의를 한 곳에서 확인하고 응대할 수 있습니다.

설정 > 병원 설정으로 이동한 뒤, 연결하려는 SNS 채널의 설정 메뉴를 선택합니다.

* 인스타그램 계정 설정
* 페이스북 메신저 설정
* WhatsApp 비즈니스 계정 설정

각 메뉴에서 현재 연결된 계정을 확인할 수 있으며, **+ 계정 추가**를 클릭해 새 계정을 연결할 수 있습니다.

> 💡 병원에서 여러 개의 SNS 계정을 운영하는 경우, 채널별로 여러 계정을 연결하여 사용할 수 있습니다.

***

### 1. 인스타그램 계정 연결

**설정 → 병원 설정 → Instagram 계정 설정**으로 이동합니다.

1. **\[+ 계정 추가]**&#xB97C; 클릭합니다.
2. 인스타그램 로그인창에서 **연**결할 계정으로 로그인한 후 화면 안내에 따라 연동을 완료합니다.
3. 연결된 인스타그램이 목록에 표시되는지 확인합니다.

<figure><img src="../.gitbook/assets/image (563).png" alt=""><figcaption></figcaption></figure>

> 💡 병원에서 여러 개의 Instagram 계정을 운영하는 경우 **+ 계정 추가**를 다시 선택하여 다른 계정을 추가할 수 있습니다. 연결된 계정은 Instagram 계정 설정 화면에서 연결된 목록을 확인할 수 있습니다.

***

### 2. 페이스북 메신저 설정

**설정 → 병원 설정 → 페이스북 메신저 설정**으로 이동합니다.



1. **\[+ 계정 추가]**&#xB97C; 클릭합니다.
2. **페이스북** 로그인 창에서 연결할 계정으로 로그인한 후 화면 안내에 따라 연동을 완료합니다.
3. 연결된 페이스북 페이지가 목록에 표시되는지 확인합니다.

> 💡   현재 연결된 Facebook 페이지가 있는 경우 해당 페이지가 목록에 표시됩니다. 인스타그램과 마찬가지로 추가로 운영하는 계정이 있다면 + 계정 추가를 통해 복수의 페이지를 연결할 수 있습니다. &#x20;

***

### **3. 왓츠앱 계정 연결**

**설정 → 병원 설정 → WhatsApp 비즈니스계정** 설정으로 이동합니다.

1. **\[+ 계정 추가]**&#xB97C; 클릭합니다.
2. **WhatsApp 비즈니스계정** 로그인 창에서 연결할 계정의 ID와 PW를 입력하여 로그인합니다.
3. 연결된 왓츠앱  계정이 목록에 표시되는지 확인합니다.

> 💡   연결된 비즈니스계정이 없는 경우 화면에 **연결된 WhatsApp 계정이 없습니다** 라고 표시됩니다.&#x20;
>
> 추가로 운영하는 계정이 있다면 **\[+ 계정 추가]**&#xB97C; 선택하여 여러 왓츠앱 계정을 연결할 수 있습니다.

***

### 💡 **운영 팁**

* 여러 지점이나 브랜드별 SNS 계정을 운영하는 경우 **각 계정을 Dr.OZ에 연결해 두면 여러 채널에서 들어오는 문의를 한 곳에서 관리하기 편리합니다.**
* 추가 계정을 연결하려면 각 SNS 설정 메뉴에서 **\[+ 계정 추가]**&#xB97C; 선택하세
